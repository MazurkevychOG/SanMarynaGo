# inbox/

Сюди завантажують **файл обміну** (`mymaps-….json`), створений на сайті через «⚙ → Експорт».
Після завантаження GitHub Action «Імпорт файлу обміну» сам додасть/оновить картки в `data/`, перебудує `data/index.json`,
перевірить каталог, закомітить результат і видалить файл із цієї теки.

Файли, окрім `*.json`, Action ігнорує.
