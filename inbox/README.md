# inbox/

Сюди завантажують **файли обміну** (`mymaps-….json`), створені на сайті через «⚙ → Експорт».
Після завантаження GitHub Action «Імпорт файлів обміну з inbox/» сам по черзі (за назвами, `…-1`, `…-2`, … у правильному порядку):

1. додасть нові й збагатить наявні картки в `data/` (без дублів), стисне нові фото в WebP;
2. додасть нові типи місць у `data/types.json` і оновить кабінети користувачів у `data/users/`;
3. перебудує `data/index.json`, перевірить каталог, закомітить результат і **видалить оброблені файли з цієї теки**.

Правила й обмеження — у головному `README.md` (розділ «Файл обміну»). Файли, окрім `*.json`, Action ігнорує.

> **Якщо файл лежить тут і не зникає** — Action не запускається. Найчастіша причина: у репозиторії немає папки `.github/` (вона не завантажилась
> разом з рештою файлів). Див. `github-setup/README.md` і розділ «Одноразове налаштування GitHub» у `README.md`.
